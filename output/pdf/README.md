# Thesis PDF archive

The public archival PDF is [`Privacy-Lens-Thesis-Final.pdf`](Privacy-Lens-Thesis-Final.pdf), compiled from `Thesis/Final` on 1 September 2026. The render timestamp is pinned with `SOURCE_DATE_EPOCH`, so the PDF is byte-reproducible: `npm run reproduce:thesis-pdf` rebuilds it and reports whether the result matches the published digest. That digest is recorded in `artifacts/final-audit/SUBMISSION_MANIFEST.json` and in `release/submission-final/SHA256SUMS.txt`, and `npm run verify:pdf` runs on every `reproduce:thesis-core` to confirm the PDF's prose still matches the corrected source and contains no retracted figure. Earlier compiled PDFs were removed from the public final branch because they duplicated content and embedded an unnecessary student identifier; their source revisions and Git history remain available.

Older PDFs remain evidence of the revision history and must not be presented as the current thesis. New revisions should use a new numbered filename and matching versioned LaTeX sources under `Thesis Version/`.
