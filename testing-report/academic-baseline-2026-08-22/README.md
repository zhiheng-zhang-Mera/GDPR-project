# Academic baseline evidence - 2026-08-22

This directory is intentionally separate from source, APK inputs, caches, and generated Android builds. It retains only reproducibility receipts and text output for the authorised WPS Office static-flow baseline.

`flowdroid-wps-rerun/flowdroid-receipt.json` records the APK hash, tool JAR hash, Android-platform directory, source-and-sink definition hash, bounded configuration, elapsed time, and completion status. `COMPLETED_NO_RESULT_ARTIFACT` means the Java process exited successfully without an XML artifact; it does not mean that FlowDroid found zero flows.

No APK binary, user data, account content, network capture, runtime tracker event, or legal-compliance verdict is stored here. This is a bounded static-analysis receipt, not evidence that WPS Office or any other application complies with or infringes the GDPR.
